# 贾维斯提示词管理

2026-11-16，用户授权将大脑贾维斯的提示词从代码固定内容改为可管理设置。

## 功能与归属

入口为组织架构管理 → 集团中枢 → 贾维斯 → 提示词。此次接通当前日常对话使用的根贾维斯，包括用户回复和后台任务通知表达。

- 编辑角色职责、交办原则和沟通方式，保存到当前 Jarvis 的设置数据库。
- 默认内容只用于首次初始化和“恢复默认”；恢复操作先进入草稿，保存后才生效。
- 预览下一轮实际组合的系统提示词，区分可编辑角色内容与系统附加的事实、工具使用说明。对话历史与工具 schema 不属于该文本预览。
- 保存使用版本冲突检查；每轮固定提示词快照，运行中保存只影响下一轮。
- 提示词不能改变工具授权；工具选择和运行时检查继续由原工具设置控制。

默认提示词强调理解需求、将耗时工作交办后结束前台轮次、按真实回执说明状态。用户可以管理这些角色规则；此功能不构成对模型一定交办的保证。

旧 Superagent 的 Router/Worker 提示词管理与独立组织进程的角色提示词不在此次修改范围，不能将此入口描述为所有角色的统一编辑器。

## 实现边界

新增 Jarvis 适配层提示词存储及组合。使用现有 settings 表中的独立设置项和版本号，不改底座领域规则或任务状态。

DSH 管理接口为 `GET /jarvis/api/prompts`、`PUT /jarvis/api/prompts` 和 `POST /jarvis/api/prompts/preview`。读取和修改均要求登录及同源访问，写入与预览还要求 CSRF，响应不缓存。

界面仍归于组织设置，使用独立能力标记；旧独立服务器不显示未接通的管理能力。
