## 管理契约

- `GET /jarvis/api/system` 返回已保存的实例、配置版本及真实进程状态。首次访问只返回可编辑根实例，不生成运行进程。
- `PUT /jarvis/api/system` 必须携带读取到的 `revision` 和完整实例配置。服务验证模型引用、直属层级、目录隔离、工具及并发 1–16。自 2026-11-18 起，单纯新增直属下级可在集团运行时保存，正在执行的任务和对话继续使用原进程。新下级初始停止，启动并确认能够接单后进入新任务的候选列表。修改既有实例的运行配置仍要求先停止受影响的实例。保存失败或版本冲突时保留原配置。
- `POST /jarvis/api/system/:id/start|stop|restart` 使用稳定实例 ID 和配置版本，仅操作目标实例。`GET /jarvis/api/system/:id` 返回安全的计数和维护记录，不暴露任务正文或会话历史。
- 所有管理路由调用 DSH `connection.requestRejection` 校验宿主登录；Host/Origin 和 CSRF 校验继续生效。页面版本冲突与“实例尚未停止”分别显示，失败保留输入。
- 宿主卸载时先注销 HTTP 路由，再关闭业务进程及原聊天。管理配置损坏或初始化失败只使管理接口不可用，原聊天仍可工作。
- 系统配置为服务器原子持久化；旧标签页草稿原样保留，可显式查看核对。含远程、多层、自动恢复或旧 Worker 组字段的草稿拒绝应用，不静默删减。
