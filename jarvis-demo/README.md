# Jarvis Executive Cockpit Demo

此目录保留早期设计稿。设置与对话的可运行实现现位于 `../jarvis/`，启动方式见 `../jarvis/README.md`；运行入口为本地 HTTP 服务，不是本目录的 `file://` 页面。

这是第一阶段的界面 Demo，模拟“董事长通过 Jarvis 管理集团，Agent／Bot 在后台协作推进”的入口。默认页面是集团经营驾驶舱；Issue → PR 是其中一个可以下钻查看的执行任务。

Demo 只验证用户体验和状态表达，不连接真实模型、GitHub、superagent Ticket 或 Worker，也不会修改仓库。

当前入口为 `jarvis-v2-preview.html`，直接在浏览器打开即可；`index.html` 保留旧版。V2 内嵌所需样式和脚本，不依赖外部资源。点击“需要我决定”中的卡片，可以查看经营任务、决策依据和下一步；在底部对话框中输入“华东增长计划”或“PR #128”可以打开对应详情。

Demo 的核心交互是低打扰推进：默认首页是长期运行后的“注意力中心”，只突出需要用户处理的事项，并用数字、状态和短标题汇总安静推进中的工作和最近交付。解释性文字和执行细节只在用户打开具体任务后出现；Jarvis 会先固定目标、交付物、边界和完成条件，之后默认安静执行。只有出现需要用户决定的歧义、工作受阻、验证失败，或已经形成可审查交付物时，才通过对话打扰用户。

页面以对话为主工作区，右侧通过“待决策 / 推进 / 风险 / 交付”切换经营上下文。删除重复的大标题和指标卡，不通过缩小字号塞入更多信息。对话正文 18px，最小辅助文字 14px；技术任务详情通过弹层展示。

桌面端按一个视口设计，对话和经营面板在必要时各自内部滚动，输入框保持可见。窄屏通过顶部“经营概览”按钮打开经营面板。面板切换和消息出现使用短动效；支持减少动态效果设置、分类按钮方向键导航和详情弹层 Escape 关闭及焦点管理。未做实际浏览器尺寸验收，不将代码层面的尺寸约束视为画面验证通过。所有产品界面采用正式产品文案；实现限制只在本文件和交付说明记录。

初始经营简报是演示快照。数据、日期、进度和依据都是示例，不代表真实集团运行或已验证结果。此页面不连接模型，不持久化对话，不执行预算批准、停机或 PR 合并。“与 Jarvis 讨论”仅产生模拟讨论消息。

## 模型设置

右上角“设置”切换到独立整页工作区，默认进入“基本设置”（`#settings`），可在左侧切换到“模型配置”（`#settings/model`）；窄屏使用顶部分类导航。返回对话保留当前消息。基本设置仅放助手名称，模型配置按连接、生成参数、请求选项分区，分别提供固定底部保存操作。设置不使用弹框。

- 连接：兼容 Chat Completions 的接口外观、Base URL、API Key、模型标识。
- 基本设置中的助手名称：默认“贾维斯”，支持修改；独立于模型配置校验、保存。名称保存后同步到标题、输入提示、既有和新增消息署名、讨论按钮等位置；放弃修改不会影响已保存名称，恢复参数默认不会重置名称。分类切换保留各自草稿，保存一部分不提交另一部分；退出设置时检查两部分是否有未保存修改。与其他配置一样，当前只保留在本次页面内存中。
- 生成参数：模型默认或自定义 Temperature / Top P（二选一）、最大输出 Tokens、推理强度。
- 请求选项：超时秒数、失败重试次数、流式输出。
- 支持字段校验、密钥显隐、参数恢复默认、修改状态、未保存离开拦截、放弃修改、键盘分类切换。

此版本是高保真交互原型。保存只写入本次页面内存，刷新会重置；API Key 不保存、不发送，保存或放弃时清空。没有真实模型请求、连通性测试、参数能力探测或持久化配置服务；状态始终为未连接。表单范围是目前设计约束，不代表任何模型都支持这些参数。真实接入时须按服务商与模型能力校验参数，不支持的选项不得提交；后台执行权限不受此表单影响。历史、长期记忆、提醒配置已移除。

页面不展示原型、演示等阶段标记，不显示设计解释；这不改变原型的实现边界。旧版 `index.html` 仅清理相应文案，当前开发与验收入口仍为 `jarvis-v2-preview.html`。

验证命令：`node jarvis-demo/settings-smoke.cjs`。覆盖脚本语法、元素引用及模拟事件交互，不替代真实浏览器的布局、焦点和多尺寸验收。
