## 原独立服务：启动

需要 Windows、Node.js 22.19+（已在本机 Node 24.22.1 验证）。运行服务不需要安装第三方依赖。

```powershell
./jarvis/start.ps1
```

脚本使用独立隐藏进程启动，输出地址 `http://127.0.0.1:4317`。可用 `-NodePath` 指定 Node 可执行文件，`-Port` 改变端口。同一数据目录只允许一个实例。

配置与对话默认位于 `%LOCALAPPDATA%/Jarvis-superagent/`：

- `jarvis.sqlite`：基本设置、模型参数、主对话及回复状态。
- `runtime.json`、`server.lock`：服务地址、PID、启动时间。
- `server.log`、`server.err.log`：启动和运行诊断，不记录聊天正文或密钥。

也可前台运行 `node jarvis/main.mjs`，通过 `JARVIS_PORT`、`JARVIS_DATA_DIR` 指定端口和数据目录，Ctrl+C 停止。独立进程可由系统进程管理器按 `runtime.json` 中的 PID 停止；重启会将未完成回复标记为中断，不自动重新消费模型请求。

## 原独立服务：使用

1. 打开运行地址，在基本设置中修改助手名称；默认“贾维斯”。
2. 模型配置中填写 Base URL、Model ID 和 API Key。Base URL 到版本根目录，例如 `https://provider.example/v1`，不要重复添加 `/chat/completions`。
3. 保存后返回对话。Enter 发送，Shift+Enter 换行；支持流式输出、停止、最近一次未完成回复的重新生成。

输入框随内容自动增高，达到窗口高度的 30% 或 240px 后在内部滚动。空白内容不可发送；生成时原位置显示停止按钮。中文输入法确认候选词不会触发发送。

### 工具与技能界面设计

设置新增“工具”和“技能”入口：`/#settings/tools`、`/#settings/skills`。列表可搜索、筛选和切换使用偏好；独立详情页可编辑工具地址、资源和访问范围，或编辑技能内容、使用范围及依赖工具。未保存修改离开时会提示，技能依赖范围不一致时会提示。

这部分是用户管理能力的高保真交互设计，当前只保存配置草稿。数据隔离在当前浏览器标签的 `sessionStorage`（`jarvis.capability-design-drafts.v1`），刷新同一标签可恢复，关闭标签后不保证保留。初始工具和技能是待确认的设计内容，不代表已安装或启用。界面保持“未连接”“草稿”“待就绪”等状态；开关只保存使用偏好草稿，不改变真实权限或工具注册。不采集工具密钥，不调用外部服务，不写入真实模型配置、会话数据库或 superagent。具体连接协议、身份验证与挂载方式仍需后续确认。

两个设置表单分别校验和保存。刷新、重开页面和重启服务后，配置与对话仍保留。模型密钥由 Windows DPAPI 按当前系统用户加密，API 只返回“已保存”状态；留空保留同一服务地址的既有密钥，点击移除后保存可删除。改变服务地址且没有重新填写密钥时，旧密钥会清除，避免发送到另一服务。

主对话会携带已有消息上下文。停止或中断的部分回复带未完成标记；失败重试复用同一用户消息，不重复插入。单条消息限制 32000 字符，累计请求上下文限制 250000 字符；超限明确拒绝，不默默裁剪历史。模型自身的上下文与输出限制仍由其服务决定。清空对话须在界面再次确认，删除当前全部对话记录。

## 原独立服务：模型协议与边界

请求使用 Chat Completions 兼容协议：`messages`、`model`、`stream`；自定义采样只发送 `temperature` 或 `top_p` 之一；输出上限映射到 `max_tokens`，推理强度映射到 `reasoning_effort`。未选择的可选参数不发送。SSE 解析支持 UTF-8 分片、CRLF、结束标记；HTTP 429/5xx 与建立连接失败可按设置重试，已有流式输出后不自动重放。

协议依据：[Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。不承诺所有兼容服务支持全部参数。仅接受 `max_completion_tokens` 的模型暂不支持自定义输出上限，可先留空；具体服务若拒绝自定义参数，应恢复模型默认。当前未进行真实服务商凭据验证。

当前是单用户、本机运行版，监听地址固定为 `127.0.0.1`；不包含远程登录、多用户、自动任务执行或 Gateway。默认允许 HTTPS 模型服务与本机 HTTP 模型服务，不跟随模型请求重定向。基础 Host/Origin/CSRF 校验和静态文件白名单不等于可直接对公网部署。

对话记录是本地明文 SQLite，密钥是单独加密的字段。服务不会把经营卡片当成模型事实，也不注册 superagent 工具。备份本地数据时请注意：DPAPI 密钥仅能由对应 Windows 用户解密。
